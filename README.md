# AnuLaya — Feel the Rhythm

A tabla composition player and practice tool for students and enthusiasts of Indian classical percussion.

Browse tabla compositions, play along at adjustable tempo, and practice with real-time microphone-based feedback. Track your progress and improve your rhythm.

## Features

- Browse and search compositions by taal, category, and difficulty
- Adjustable playback tempo (20–300 BPM) with taal-aligned grid display
- Practice mode with tabla or vocal input and real-time scoring
- Laykari polyrhythm trainer
- Create and share compositions using bol notation
- Playlists with custom tempo overrides
- Practice calendar and session history
- Offline playback with automatic caching
- Roman and Devanagari script display
